# axeldld.github.io

Personal portfolio of **Axel Deliaud** — software & web developer, Epitech Lyon.

## Stack
One self-contained `index.html` — vanilla JS, no build step, no dependencies.
Embedded WebP screenshots, FR/EN toggle, live Corewar arena hero (canvas).

## Develop
Open `index.html` in a browser. That's it.

## Deploy
- **Vercel**: push to main — static files are served as-is.
- **GitHub Pages**: Settings → Pages → "Deploy from a branch" → `main` / `(root)`.

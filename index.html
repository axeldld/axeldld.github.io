Case study

Corewar Arena

A virtual arena where assembly-level champions battle for survival, built with a custom VM and assembler.

Overview

Corewar builds a virtual arena where programs fight with no mercy. The goal: design the program that survives the longest.

Engineering focus

Champions are written in Redcode, a simplified assembly language, then loaded into the arena to execute and clash. The project proves understanding of computer architecture, low-level programming, and algorithmic optimization.

My RPG

A 2D role-playing game with exploration, combat, and custom-built maps.

Overview

A video game written in C with CSFML: the player moves through a map, interacts with objects and NPCs, and fights monsters. Mine is a 2D side-view game where you can jump, attack, and upgrade your skills.

What I built

This project grew my programming, graphics, and game-design skills. Every map in the game was created by me.

Organized

Overview

Organized consists of building a sorting algorithm for hardware components — demonstrating data structures, sorting algorithms, and performance optimization.

Core goals
